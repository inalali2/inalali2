### 🔷 [Canadian Crude Differential Pipeline](https://github.com/inalali2/canadian-crude-differential)
`Python` `SQLite` `GitHub Actions`

Tracks the discount of Western Canadian Select (WCS) to WTI crude, using 21 years of data from the U.S. EIA and the Government of Alberta.

- Automated ETL that reruns safely, handles revised source data, and falls back to manual input when a feed breaks
- 27 unit tests run in continuous integration
- Structural break tests plus historical VaR and expected shortfall by regime, correcting an autocorrelation issue that caused false breaks in simulation
